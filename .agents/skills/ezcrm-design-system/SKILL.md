# EZCRM Design System

Use this skill when creating or standardizing EZCRM UI.

## Rules

- Preserve EZCRM visual identity.
- Reuse project UI primitives first.
- Maintain consistent spacing, border radius, shadows, controls, cards, tables, badges, modals, and typography hierarchy.
- Avoid one-off inline visual systems.
- Do not introduce random colors.
- Do not make every section a card.
- Use emphasis sparingly.
- Optimize information density for CRM workflows.
- Keep desktop workflows efficient.
- Ensure mobile remains usable.
- Favor clear operational UI over decorative effects.
- Reuse patterns already present in successful EZCRM pages.
- Avoid a new dependency unless explicitly justified.

Before a large redesign, inspect existing components and neighboring pages first.
